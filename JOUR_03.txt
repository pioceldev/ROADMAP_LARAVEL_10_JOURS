JOUR 03 — BASE DE DONNÉES, MIGRATIONS ET SEEDERS
================================================================================

1. OBJECTIF DU JOUR
--------------------------------------------------------------------------------
- connecter ton application à une base de données,
- créer et comprendre les migrations,
- créer et comprendre les seeders,
- remplir la base de données avec des données fiables,
- préparer les modèles Eloquent,
- vérifier le cycle complet base → migration → modèle → données.

Ce qu'il faut retenir : une migration est l'historique de ta base, un seeder est
un moyen reproductible de remplir la base, et les deux doivent être utilisés pour
garder ton environnement reproductible.

2. OBJECTIFS PRÉCIS
--------------------------------------------------------------------------------
- vérifier ta connexion à la base,
- créer une migration,
- créer un seeder,
- remplir la base,
- créer un modèle associé,
- vérifier la cohérence entre migration et modèle,
- utiliser php artisan migrate et php artisan db:seed,
- expliquer les différences entre migration et seeder.

3. PRÉREQUIS
--------------------------------------------------------------------------------
- Jours 1 et 2 faits,
- un projet Laravel,
- une base de données accessible localement,
- savoir lire une erreur de connexion SQL,

8. COMMANDES UTILES LE JOUR 03
--------------------------------------------------------------------------------
- créer une migration :
    php artisan make:migration create_articles_table
- créer un seeder :
    php artisan make:seeder ArticleSeeder
- créer une factory :
    php artisan make:factory ArticleFactory
- lancer les migrations :
    php artisan migrate
- lancer les seeders :
    php artisan db:seed --class=ArticleSeeder
- voir les migrations :
    php artisan migrate:status

Tu peux lire :
- /database/migrations,
- /database/seeders,
- /database/factories,
- /app/Models.

9. EXERCICES PRATIQUES
--------------------------------------------------------------------------------
Exercice 03.1 — Connexion à la base
- configure la base dans .env,
- teste la connexion,
- vérifie que tu peux interagir avec la base.

Exercice 03.2 — Migration
- crée une migration,
- écris les colonnes,
- lance la migration,
- vérifie la table créée.

Exercice 03.3 — Seeder
- crée un seeder,
- remplit quelques lignes,
- lance le seeder,
- vérifie que les données existent.

Exercice 03.4 — Modèle
- crée un modèle,
- vérifie que le modèle correspond à la migration,
- utilise le modèle pour lire des données.

Exercice 03.5 — Factory
- crée une factory,
- génère des données,
- vérifie que les données sont cohérentes.

Exercice 03.6 — Exemple complet
- crée une table,
- crée un seeder,
- crée une factory,
- remplit la base,
- vérifie que tout est cohérent.

Exercice 03.7 — Données fiables
- remplit la base avec des données réalistes,
- vérifie que les données sont cohérentes,
- garde un seeder reproductible.

Exercice 03.8 — Questions sans support
- à quoi sert une migration ?,
- à quoi sert un seeder ?,
- quelle différence entre migration et seeder ?,
- comment remplir la base de manière reproductible ?,
- comment vérifier qu'une migration est bien appliquée ?.

10. MINI-PROJET DU JOUR
--------------------------------------------------------------------------------
Objectif : une base de données alimentée et reproductible.

Ce que tu fais :
- une migration,
- un seeder,
- une factory,
- un modèle,
- une base remplie,

Ce qu'il faut valider :

- tu sais organiser une base simple et reproductible.

- remplir la base sans seeder,
- chercher des tutos au lieu de la doc,
- tomber sur des tutoriels trop anciens ou pas à jour,
- confondre migration et seeder.
