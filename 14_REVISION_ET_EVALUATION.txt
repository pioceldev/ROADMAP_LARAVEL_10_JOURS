2. EXERCICES PRATIQUES DE RÉVISION
--------------------------------------------------------------------------------

Exercice 1 — Reproduction sans notes

Choisissez 3 notions suivantes :
- créer un contrôleur et une route,
- faire un layout Blade,
- créer une migration et la lancer,
- créer un modèle et une factory,
- définir une relation 1:N,
- valider un formulaire avec @csrf et old(),
- protéger une route par auth,
- créer une route API et une API Resource,
- écrire un test basique,
- lire un log ou déboguer une erreur.

Reproduisez chaque notion dans un projet vierge ou dans votre projet de formation
sans copier-coller. Expliquez chaque ligne à voix haute.

Exercice 2 — Explication orale

Choisissez 3 notions et expliquez-les sans regarder la documentation, comme si
vous deviez les enseigner à un autre développeur qui vient de finir PHP.

Exercice 3 — Lecture de code

Prenez un fichier de votre projet et expliquez :
- ce que fait chaque méthode ou bloc important,
- pourquoi il est organisé ainsi,
- comment il se connecte avec le reste du projet,
- ce qui serait à améliorer.

Exercice 4 — Audit rapide

Dans votre projet, trouvez :
- une route,
- un contrôleur,
- une vue Blade,
- une migration,
- un modèle,
- une factory ou un seeder,
- une validation,
- une autorisation (middleware ou policy),
- une réponse API ou un contrôleur web,
- un test,
- un fichier .env important.

Expliquez à quoi chaque élément sert dans votre projet.

3. MINI-DÉFIS
--------------------------------------------------------------------------------

Défi 1 — Formulaire complet
- Créez un formulaire de création avec CSRF, validation, messages d'erreur,
  old(), et un upload optionnel.
- Testez les cas valides et invalides.

Défi 2 — Relation avec contrainte
- Créez une relation 1:N avec une contrainte métier.
- Vérifiez que seules les données autorisées sont accessibles.

Défi 3 — API avec erreur cohérente
- Créez un endpoint qui crée une ressource.
- Retournez une erreur JSON cohérente si la validation échoue.
- Protégez l'écriture si possible.

Défi 4 — N+1 volontaire puis correction
- Écrivez du code qui provoque intentionnellement un N+1.
- Observez le nombre de requêtes.
- Corrigez avec with().
- Comparez.

Défi 5 — Refactorisation
- Prenez un contrôleur trop chargé et faites-le plus léger.
- Expliquez ce que vous avez déplacé et pourquoi.

Défi 6 — Policy ou gate
- Créez une règle d'autorisation basée sur un contexte simple.
- Vérifiez que les actions non autorisées sont bloquées.

Défi 7 — Test qui devrait échouer
- Écrivez un test qui devrait échouer si une règle est violée.
- Vérifiez que le test échoue comme prévu.
- Corrigez le code si nécessaire.

Défi 8 — Debug volontaire
- Introduisez une erreur simple dans votre projet.
- Diagnostiquez-la avec les logs ou le mode debug.
- Corrigez-la.

Défi 9 — Lecture du cycle de requête
- Prenez une requête réelle et expliquez chaque étape du cycle Laravel.

Défi 10 — Documentation minimale
- Écrivez un README minimal qui permette à un autre développeur de lancer votre
  projet.

7. LISTE DES COMPÉTENCES À VÉRIFIER AVANT DE CONSIDÉRER LA FORMATION
  SUFFISAMMENT EXPLOITÉE
--------------------------------------------------------------------------------

Une formation de 10 jours ne rend pas expert. Mais pour en tirer un réel
bénéfice, vous devez au moins pouvoir :

1. Créer et configurer un projet Laravel.
2. Lire la documentation officielle pour avancer seul.
3. Créer une application avec :
   - routes,
   - contrôleurs,
   - vues Blade,
   - migrations,
   - modèles,
   - relations,
   - validation,
   - auth basique,
   - autorisations basiques,
   - API simple si besoin,
   - tests basiques,
   - documentation de démarrage.
4. Déboguer les erreurs classiques.
5. Utiliser Artisan pour les tâches courantes.
6. Raconter ce que vous avez appris et ce qui vous reste fragile.

Si vous ne pouvez pas faire ces choses sans copier-coller aveugle, la
formation n'est pas terminée à votre niveau. Reprenez les jours concernés.

--------------------------------------------------------------------------------
8. COMMENT UTILISER CE FICHIER
--------------------------------------------------------------------------------

1. Faites la révision d'un jour avant de commencer le jour suivant.
2. Choisissez les exercices qui correspondent à vos points faibles.
3. Choisissez les mini-défis pour tester votre autonomie.
4. Faites l'examen final à la fin des 10 jours ou après un temps de
   révision.
5. Utilisez la grille d'évaluation pour voir ce qui est vraiment acquis.
6. Notez les cases "non maîtrisé" dans le suivi et prévoyez de les retravailler.
