================================================================================
11 — RESSOURCES LARAVEL
================================================================================

Ce fichier regroupe les ressources utiles pour les 10 jours et pour continuer
à apprendre après la formation.

Rappel important :
- Les liens ont été vérifiés pendant la recherche, mais les pages web changent.
- Vérifiez toujours la version de Laravel que vous utilisez et privilégiez la
  documentation officielle de cette version.
- Une ressource payante est indiquée comme telle si son caractère payant est
  identifiable.
- Une ressource non vérifiable est signalée comme telle.

8. RESSOURCES NON VÉRIFIÉES OU À TRITER AVEC PRÉCAUTION
--------------------------------------------------------------------------------

- Les ressources payantes derrière un abonnement ne sont pas détaillées ici
  dans leur intégralité. Si une ressource est derrière un paywall, c'est souvent
  le cas de Laracasts.
- Les blogs externes (Medium, Dev.to, autres) sont utiles mais varient en qualité
  et en fraîcheur.
- Les vidéos YouTube sont utiles pour l'intuition, mais les versions de Laravel
  peuvent différer de la vôtre.
- Les liens doivent être vérifiés à chaque utilisation, surtout si vous les
  utilisez longtemps après la création de ce fichier.

--------------------------------------------------------------------------------
9. COMMENT CHOISIR SES RESSOURCES
--------------------------------------------------------------------------------

La règle simple :
1. Documentation officielle en premier.
2. Puis ressource pédagogique récente et cohérente avec votre version.
3. Puis l'exemple dans votre projet.
4. Puis la vidéo ou l'article pour compléter.

Ne multipliez pas les ressources pour "tout savoir". Multipliez les ressources
pour "comprendre quand vous êtes bloqué", puis codez.
